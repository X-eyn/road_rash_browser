# NOTICE

This directory contains a non-commercial fan preservation port of **Road Rash**
(1996, PC). The port's own source code is MIT licensed (see LICENSE).

The following material is **not** licensed by this project and remains the
property of Electronic Arts:

- `Road_Rash/` — the original game installation (user-supplied).
- `web/assets/art/` — original JPEG screens, portraits, postcards and results.
- `web/assets/sprites/` — original rider, traffic, HUD, cloud and horizon art.
- `web/assets/track/` — original prop atlases and roadside art.
- `web/assets/tex/` — original road, verge and start/finish textures.
- `web/assets/audio/sfx/` — original WAV sound effects.
- `web/assets/fonts/` — Futura Condensed fonts from the original game.
- `web/data/` — decoded original text, bike/rider tables and course data.
- `preview/` — reverse-engineering previews derived from the game.

Do not redistribute the extracted original assets. This build is intended for
local use with a legally owned copy of the original game.

No original CD music is included. The soundtrack is a procedural tribute
generated by the browser.

Road Rash was published by Electronic Arts; the PC version was developed by
Papyrus Design Group. Three.js is MIT licensed. Format research was assisted
by REA (morluto/rea).
